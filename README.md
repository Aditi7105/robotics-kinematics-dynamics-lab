# Robotics Kinematics and Dynamics Lab using Scilab

This repository contains Scilab-based robotics laboratory experiments and reports related to robot kinematics and dynamics.

## Topics Covered

- Forward Kinematics
- Inverse Kinematics
- DH Parameters
- Jacobian Matrix
- Robot Dynamics
- Trajectory Planning

## Software Used

- Scilab
- Robotics Mathematical Modeling

## Repository Contents

- PDF experiment reports
- Simulation outputs
- Mathematical derivations
- Graphs and analysis

## Applications

These experiments are useful for understanding robotic manipulators, motion planning, and industrial robotics systems.
